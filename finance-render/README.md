# 经营财务工作台 · Render在线验收站

独立部署目录，不改变仓库根目录原有AI助手。使用finance-render分支及本目录render.yaml。

这是在线多人试账候选版，不是已验收的法定会计系统。首次初始化为空账，仅保留公司、门店及仓库结构；不导入离线演示交易或生成员工默认密码。

## 部署

Blueprint创建一个新加坡免费Web服务及同区免费PostgreSQL。数据库仅允许内部连接，数据库连接串由fromDatabase注入。OWNER_EMAIL在Render中设置，BOOTSTRAP_CODE由平台生成；所有真实环境变量和密码不得提交Git。

在/healthz可检查服务与数据库连接。首次管理员访问/auth/bootstrap，使用Render Environment中BOOTSTRAP_CODE和配置的OWNER_EMAIL设置自己的密码（12至128字符）。管理员设置仅可执行一次，完成后用邮箱登录。

员工：管理员先在人员与权限建立员工及数据范围，再点“开通/重置登录”，把24小时单次链接交给对应员工，员工自行设置密码。支持邮箱或员工代号登录，不依赖ChatGPT账号。停用人员立即失去业务访问；密码重置后旧会话失效。

## 运行与数据

Node.js24，npm install --omit=dev，npm test，npm start。服务监听0.0.0.0及PORT。Postgres储存业务状态、凭证附件、散列密码、会话令牌哈希和开通令牌哈希。沿用原有乐观并发版本控制及1MB业务状态保护。附件总配额100MB、单文件5MB；生产前需迁移对象存储、分表分页、自动备份和恢复演练。

不接受浏览器提供的用户身份头，身份只从服务端数据库会话读取。认证Cookie为Secure、HttpOnly、SameSite=Strict。状态写入需同源Origin。密码scrypt加随机salt；登录限流。bootstrap码不进入源代码、客户端静态文件、日志或聊天。

## 试验及手机

请在两个浏览器/手机账号间验证商品、收货、报销和付款状态共享、公司范围和采购价格隔离。手机在HTTPS顶层页面使用采购验收或数量收货；显式授权后置相机。识别只定位商品，确认数量后再提交。支持手工条码输入和本地EAN-13/EAN-8后备解码，未保证所有设备和码制。

免费Web服务闲置会休眠，免费Postgres30天到期；只用于测试。正式经营前须确认持续可用的付费计划及备份、数据恢复和业务口径，不能把免费站当作长期账本。

部署创建不等于上线成功；须看到live状态并完成健康、登录、共享、权限、附件及相机实测。当前源码不附带任何真实财务数据或密码。
